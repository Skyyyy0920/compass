### Environment Interaction 8
----------------------------------------------------------------------------
```python
# Now, let's get all liked songs using the access token.
# We will handle pagination to get all liked songs.
liked_songs = []
page_index = 0
while True:
    response = apis.spotify.show_liked_songs(access_token=access_token, page_index=page_index, page_limit=20)
    if not response:
        break
    liked_songs.extend(response)
    if len(response) < 20:
        break
    page_index += 1

liked_songs  # Check the liked songs list.
```

Execution successful.
